# Remove specific plot from a scene or schema

This function removes a specific plot from a `plotscaper` scene or
schema.

## Usage

``` r
remove_plot(x, id = NULL)
```

## Arguments

- x:

  A plotscaper scene or schema

- id:

  A string id of the plot. See
  [id](https://bartonicek.github.io/plotscaper/reference/id.md)

## Value

The scene or schema back
