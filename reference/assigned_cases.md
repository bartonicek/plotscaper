# Get assigned cases

This function returns the cases of the data which are assigned to a
specific permanent group within a `plotscaper` scene.

## Usage

``` r
assigned_cases(x, group = 1)
```

## Arguments

- x:

  A `plotscaper` scene

- group:

  The group to retrieve the cases of (can be: 1, 2, or 3)

## Value

A numeric vector of case ids
