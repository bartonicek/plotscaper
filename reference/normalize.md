# Normalize a plot

This function switches the representation of a plot to a normalized one,
e.g. spineplot, spinogram, etc...

## Usage

``` r
normalize(x, id = NULL)
```

## Arguments

- x:

  A `plotscaper` scene

- id:

  A string id of the plot. See
  [id](https://bartonicek.github.io/plotscaper/reference/id.md)

## Value

The scene or schema back
