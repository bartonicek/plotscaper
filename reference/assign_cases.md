# Assign cases to a group

This function assigns specific cases (rows of the data) to a permanent
group within a `plotscaper` scene or schema. Permanent group assignments
are only removed by double-clicking.

## Usage

``` r
assign_cases(x, cases = NULL, group = 1)
```

## Arguments

- x:

  A `plotscaper` scene or schema

- cases:

  The cases (rows) to select

- group:

  The group to assign the cases to (can be 1, 2, or 3)

## Value

The scene or schema back
