# Set interactive scene layout

This function sets a layout for a `plotscaper` scene. Similar to the
[`graphics::layout`](https://rdrr.io/r/graphics/layout.html) function.

## Usage

``` r
set_layout(x, layout = NULL)
```

## Arguments

- x:

  A `plotscaper` scene

- layout:

  A numeric matrix of plot ids, arranged into contiguous rectangles

## Value

The scene or schema back
