# Add a plot to a scene or schema

This function adds a plot to an existing `plotscaper` scene or schema.
Not meant to be called directly but instead with a wrapper function such
as
[`add_scatterplot()`](https://bartonicek.github.io/plotscaper/reference/add_scatterplot.md).

## Usage

``` r
add_plot(x, spec)
```

## Arguments

- x:

  A plotscaper scene or schema

- spec:

  A list with the plot specification

## Value

The scene or schema back
