# Select cases of the data

This function selects specific cases (rows of the data) within a
`plotscaper` scene or schema by assigning them to transient selection.
Transient group assignment is removed by clicking.

## Usage

``` r
select_cases(x, cases = NULL)
```

## Arguments

- x:

  A `plotscaper` scene or schema

- cases:

  The cases (rows) to select

## Value

The scene or schema back
